아래 사이트에서 제공하는 모든 구성 요소를 사용하여 제작 할 것이다.
UI/UX적인 요소를 아래 사이트에서 가이드/제공하는 내용을 최선을 다해 반영하라.
https://ui.shadcn.com/

https://ui.shadcn.com/docs/skills

각 페이지 또는 element에 사용 될 아이콘은 아래 사이트에서 제공하는 아이콘을 모두 받아 사용하라
https://lucide.dev/icons/

웹 서비스 제작은 아래와같은 순서로 제작하도록 유도한다
아래 기능 별 요구사항은 만족하되, 사용자가 비 개발자여도 만들 수 있도록 최대한 쉬운 방법을 제공
웹사이트의 테마를 선택할 수 있게하고 테마 선택 버튼은 우상단에 두도록 해라.
다크 20종, 그레이 20종, 라이트 20종의 프리셋을 제공하라. 
(모든 프리셋은 텍스트와 Element, Page, 배경색의 컬러 배치가 가독성이 뛰어나게 구성)

텍스트 크기 조절 기능을 테마 버튼 왼쪽에 배치하고 12px를 기준으로 좌 우에 -, + 버튼을 배치하여 각 버튼 클릭 시 1px씩 증감하게 하라

1. page 구성 & page 별 layout 구성
2. 각 layout에 연결 될 Data base와 Data base의 구성 요소
3. 최종 동작 검증 (Sample data 입력 및 page 이동, db와 element가 잘 연결되었는지 실제 data in/out으로 검증)

page 구성 기능은,
1. 각 page를 더블클릭 시 rename,
2. drag & drop 통해 위치 이동, (drage 중에는 대롱거리는 연출)
3. page 이름 우측에 빨간 휴지통 모양 아이콘 통해 삭제 기능 제공

layout 구성은
1. 게시판, 통계 분석을 위한 dashboard, 체팅 창등 일반적인 통계분석을 웹서비스에서 제공하는 레이아웃의 프리셋을 제공하여 선택할 수 있게 하라.
1. 좌측의 element list에서 drag&drop을 통해 자유롭게 배치 (drage 중에는 대롱거리는 연출)
2. 오와열은 자동으로 픽스되도록 grid에 맞춰 배치되도록 함
3. 크기조절은 좌우상하 라인과 각 모서리를 마우스 drag로 가능하게 하라
3. 우측에는 layout에 배치 한 element를 선택 시 해당 element의 속성에 맞는 상세 설정 기능 제공

DB 구성 화면은,
1. Class diagram 형식으로 제공
2. 해당 화면에는 Page와 해당 Page에 등록 된 Element 그리고 DB등이 Node로 배치
3. 각 Page Element와 DB는 point to point로 마우스 drag & drop을 통해 연결시킬 수 있어야 한다.
4. 각 Node는 마우스 drag & drop으로 자유롭게 이동할 수 있게하라.
5. 자동 정렬 버튼을 눌러 최대한 연결 라인을 방해 하지 않는 구성으로 각 Node가 재배치 될 수 있는 기능을 제공하라.
